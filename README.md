## 🚀 Installation

### **Requirements**
- ✅ Minecraft Server 1.20+
- ✅ Spigot/Paper Server
- ✅ Java 17+

### **Download & Install**
1. 📥 Download the latest `OfirMobs.jar` from [Releases](../../releases)
2. 📁 Place the file in your server's `plugins/` folder
3. 🔄 Restart your server
4. ✨ Start spawning epic bosses!
